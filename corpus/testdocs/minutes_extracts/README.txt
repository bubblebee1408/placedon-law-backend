Intentionally empty.

Minutes books are not public and none was sought for this corpus. The only minutes here are ICSI's
five published specimens, in ../icsi_specimens/.

The realistic remaining source is a minutes extract quoted verbatim inside an ROC s.454 adjudication
order — orders often reproduce the offending passage when describing the defect. None was obtained:
mca.gov.in returned HTTP 403 to automated fetches, and the 68-order corpus behind
checker/ss/RULES.md is not stored in this repo.

This is the corpus's single largest gap. Every real document here is compliant, so the corpus can
measure the scanner's FALSE POSITIVE rate but not its FALSE NEGATIVE rate. Filling this directory
with real defective minutes is the highest-value next step. See MANIFEST.md.
