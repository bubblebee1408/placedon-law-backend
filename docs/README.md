# docs/

Every document in this repository, filed by **what kind of statement it makes**. A folder
tells you how far to trust a document before you open it.

**Start with [START_HERE.md](START_HERE.md).** Then use the table below. For code, use
[REPO_MAP.md](REPO_MAP.md), which is generated by `python3 scripts/repo_map.py`; never edit it
by hand.

| Folder | What it holds | Tense | Trust it as |
|---|---|---|---|
| [architecture/](#architecture) | how the system is built and what each feature is | present | current; if it disagrees with the code, the code wins, so fix the doc |
| [guides/](#guides) | runbooks and how-tos | present | instructions you can follow today |
| [policy/](#policy) | rules for sources, evidence, metrics, scope | present | binding |
| [plans/](#plans) | numbered plans and plan folders | future | intent, not fact; check [PLAN_00_INDEX](plans/PLAN_00_INDEX.md) for each plan's status |
| [evidence/](#evidence) | ledgers, retractions, source defects, proofs, failure analysis | past + present | the record; never rewritten, only appended |
| [reports/](#reports) | dated session, loop and audit reports | past | what was true on its date |
| [product/](#product) | buyer, personas, outreach, retired products | mixed | read with PLAN_20, which supersedes the older buyer documents |
| [market/](#market) | competitor and market analyses | dated | analysis of *other* products; it is not our design |
| [research/](research/) | dated research passes, red-team reports, UX research | past | sourced findings as of their date |

`scripts/check_doc_refs.py` enforces the tense rule: every path a present-tense document
cites must exist; plans may cite what is not built yet; history may cite what has been
deleted. See [CONTRIBUTING.md](../CONTRIBUTING.md#documents).
