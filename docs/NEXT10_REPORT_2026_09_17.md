## The three findings worth your time

**1. A real filing encodes `1` as `7`, and both models agreed on the wrong CIN.** Route Mobile's
28-Jan-2025 outcome prints `L72900MH2004PLC746323` in the letterhead of pages 1, 3 and 4 and
`...146323` on page 2. The tell was the phone number in the same block: `+97 22 4033`. **India is
+91.** One glyph is encoded as `7` throughout, and it corrupts the CIN with it. pdfplumber and
poppler share no code and produce the same substitution, so it is the source, not our reader.
Preserved, not repaired — a CIN is an identity field, and a silent fix keeps the answer confident
while changing which company it is about. Recorded as **SD-006**.

The method failure is the point: **two models agreed on the corrupted value** because both read the
same defective text, faithfully. That is correct model behaviour and a failure of agreement as a
proxy for truth. The review now carries a *"The document against itself"* column that flags it —
1 of 16 agreement rows, no false positives.

**2. The summary traced a fabrication welded to a true clause.** "The auditors have resigned"
alone was refused. The same words bolted onto a supported sentence came back **traced**, and printed
in the lawyer-facing body with an anchor — because coverage was a *fraction*, so true material
diluted the false clause. Fixed, and re-verified: the conjoined form now refuses while genuinely
supported sentences still trace.

**3. Tests that pass whatever the code does — four times in one night.** A fixture too short to trip
its own bar; a suite asserting over one document id; a fixture that passed with the fix reverted; and
a measurement run eleven times with the variable that mattered overridden. Each was caught, and the
answer is now committed: a **mutation kill harness** that breaks the implementation on purpose and
fails if the suite stays green. Eleven mutants, 0.07 s, already inside the gate. Independently
checked by mutating a threshold by hand: the suite goes 89/89 → 82/89.

## Over-refusal — measured, because nobody could measure the real thing

D4's thresholds moved hard after finding 2. The risk that creates is the opposite one: **a tracer
that refuses everything is as broken as one that traces everything, and looks identical in a
pass/fail table.** With no Opus available, this was measured against the fixture instead. Eight
realistic, genuinely-supported lawyer sentences: **7 traced.**

The one refusal is characterisable, and it is a real limit rather than a rounding error:

| sentence | verdict |
|---|---|
| short, using a synonym the source does not use | **refused** |
| short, using the source's own verb | traced |
| **long, using the same synonym** | **traced** |

A short sentence introducing one unfamiliar word is refused because that word is a large share of its
small vocabulary; the same word survives in a longer sentence. **Refusal therefore depends on
sentence length, which the model controls** — the mirror image of the original defect, where the span
budget scaled with sentence length. Same structural weakness, opposite direction. Open, not fixed.

**This is a proxy.** Whether real Opus prose clears these bars is unmeasured and unmeasurable until
the account is funded. It is the first thing a funded run should report.
