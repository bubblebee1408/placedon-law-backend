# Documentation debt — measured, triaged, 27 September 2026

The founder's complaint was specific: *"there are many useless, unwanted things which have been
confused by different models which I'm using… If any software engineer is hired in the future,
he'll be confused about what you are building."*

This is that, counted. Every `path/like.this.py` written in backticks or invoked in a shell block
across every `.md` in the repo was resolved against the filesystem. **78 referenced paths did not
exist.** After §1 and §2 were fixed the same scan measures **44**, of which 29 are the history
references in §4 that are correct by design. Worktrees under `.claude/worktrees/` are excluded throughout — seven full copies of the
engine live there, three `locked`, and they belong to other sessions.

Reproduce: the scan is ~25 lines of `os.walk` + two regexes; it is not committed as a script
because a script that must be run is weaker than a gate check, and the right end state is a gate
check. See §4.

|---|---|---|
| `.claude/commands/build.md` | `python3 scripts/verify.py` | `./scripts/verify_green.sh` |
| `.claude/commands/fix.md` | `python3 scripts/verify.py` | `./scripts/verify_green.sh` |

| `.claude/scripts/verify.py` | a wrapper that `runpy`'d the missing file | **deleted** |

**Worse than a broken command: a fabrication instruction.** `/build`, `/fix` and `/loop` each told
an agent that if a bug escaped it must *"add a check to `scripts/verify.py` with its story in
`because=`"*. There is no such file and **`because=` appears in zero `.py` files in this
repository.** An agent obeying that instruction would have had to invent a central check file and a
parameter convention — creating precisely the unwanted code the founder is objecting to. The
instruction now points at the real convention: a `check(cond, label)` call inside the module's own
`_test()`, which is what 146 of the 153 `check` definitions here already are.

`.claude/scripts/verify.py` was executable and guaranteed to raise `FileNotFoundError`. Deleted.

**After the fix, category count is zero.** No `.md` in this repo now invokes a script that is not
on disk.

## 4. References that are correct because the document is history — do not touch

29 paths. `docs/RETIRED_POSH.md` citing `scripts/ingest_posh.py`, `docs/RETRACTIONS.md` citing a
withdrawn plan, `docs/CLAIMS_LEDGER.md` citing the state on its own date, `.claude/memory/LESSONS.md`
citing the file an incident happened in, and every dated `.claude/plans/loop-*.md` and
`docs/research/*`.

**These are not debt. They are the record, and editing them is the failure mode, not the fix.**
`CLAIMS_LEDGER.md` says so in terms: its denominator *"must not be quietly restated later."* Any
future sweep of this kind must separate the two categories before it deletes anything — a
find-and-replace across `*.md` would destroy the repository's memory of its own corrections.

**The right end state is a gate check, not a cleanup.** A test that resolves every backticked path
in the active document set and fails on a miss, with an explicit allow-list for the history files
above. That converts this document from a snapshot into an invariant, and it is the only version of
this work that cannot rot. Not built here, because it needs the active/history boundary agreed
first — that boundary is a judgement, and §2 shows it is the founder's to make.
